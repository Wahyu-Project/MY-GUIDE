Elasticsearch - Kibana

Tools Elasticsearch adalah search engine & analytics library yang bertugas mengumpulkan, mengindeks, serta menyimpan data log server AMP secara real-time dan terpusat lalu divisualisasikan melalui Kibana untuk merubah data dalam bentuk grafik dan diagram.

1.Elasticsearch - Kibana Dashboard

Halaman Dashboard Elasticsearch - Kibana merupakan pusat pemantauan traffic API dan performa sistem secara real-time, menyajikan ringkasan metrik utama seperti total request, statistik status transaksi, distribusi beban server core, serta tren lonjakan transaksi.

URL Kibana
https://integrasi-admin.sig.id/kibana/login

Fokus monitoring pada tools Elastic - Kibana yaitu untuk melihat berapa jumlah total Request Endpoint yang masuk kategori Success, Exception dan Failed pada retensi 60 hari kebelakang. Data log yang lebih dari 60 hari akan dilakukan housekeeping.

2.Monitoring Status Code

Dari data endpoint yang memiliki log pada tools Elastic - Kibana tersebut bisa dijadikan acuan atau rekomendasi untuk kebutuhan pengecekan dan troubleshooting.

Success (Res Code 200)

Analisis Data: Request Success dengan Res Code 200 menandakan Request dari client berhasil diterima, diproses, dan dikembalikan oleh sistem tanpa ada kendala.

Action: Tidak ada Action yang perlu dilakukan, jika user masih mengeluhkan kendala, konfirmasikan bahwa sistem berhasil merespons request. Arahkan pengecekan ke sisi eksternal (koneksi internet user, atau tampilan frontend/UI user).

Failed (Res Code 400)

Analisis Data: Request gagal diproses yang umumnya disebabkan oleh kesalahan di sisi Client dikarenakan beberapa kondisi seperti format request salah, autentikasi gagal (token invalid), atau endpoint tidak ditemukan.

Action: Jika terdapat request Failed dalam jumlah masif, tim Helpdesk wajib melakukan penarikan data log. Periksa kolom request body dan response body. Hasil analisis dilaporkan kepada PIC SIG (Pak Kardo) untuk dikoordinasikan ke pihak user dan informasikan ke tim Synxchro untuk pengecekan service AMP.

Exception (Res Code 500)

Analisis Data: Request gagal karena terjadinya malfungsi pada sistem internal (Server-side error) yang dapat disebabkan karena database connection loss, timeout ke layanan pihak ketiga, atau bug aplikasi.

Action: Jika terdapat Exception masif, segera tarik data daftar endpoint dan cek detail error pada kolom request/response body. Informasi diserahkan kepada PIC SIG (Pak Kardo) dan diinformasikan juga ke tim Synxchro untuk segera ditindaklanjuti.

Note: Untuk detail error Failed dan Exception dapat dilihat di kolom Request dan Response pada menu detail request Elasticsearch - Kibana.

3.Flow Penarikan Data Log Endpoint

Sehubungan dengan kebutuhan data report weekly dan report monthly, team helpdesk dapat melakukan penarikan (ekspor) data log endpoint berdasarkan periode report.

Log Endpoint Active & High Avg Duration

  1. Modify Waktu sesuai dengan periode yang diinginkan.
  2. Klik Option (titik 3) pada bagian Total By Endpoint lalu pilih more dan maximize.
  3. Setelah data log muncul, team helpdesk dapat melihat informasi execution_time_ms dan response_body_length pada masing-masing endpoint.
  4. Team helpdesk dapat mendownload/export data pada menu Option (titik 3).

Log Failed & Exception

  1. Buat Filter request berdasarkan Log request Failed & Exception.
  2. Modify Waktu sesuai dengan periode yang diinginkan.
  3. Klik Option (titik 3) pada bagian Detail Request lalu pilih more dan maximize.
  4. Setelah data log muncul, team helpdesk dapat melihat informasi log error secara detail pada masing-masing endpoint.
  5. Team helpdesk dapat mendownload/export data pada menu Option (titik 3).

Note: Log Endpoint Active berdasarkan Tier 1 - Log 2 Minggu (0-14 hari), Tier 2 - Log 30 Hari (15 - 30 hari), dan Tier 3 - Log 60 Hari (31 hari - 60 hari).
