API Gateway Console

Tools API GATEWAY PLATFORM (CONSOLE) adalah bagian dari API MANAGEMENT PLATFORM yang memungkinkan developer mendokumentasikan, membuat (Production), menghapus (Delete), merubah connection, menonaktifkan (Undeploy), mengaktifkan kembali (Redeploy), dan melakukan pencarian API/Endpoint yang tersedia.

  • Informasi Akses
  • Landing Page Menu
  • Proses Pembuatan

1.Informasi Akses Login

API GATEWAY PLATFORM (CONSOLE) dapat diakses menggunakan link untuk environment Production maupun Development berikut:

2.Landing Page Menu

Ketika anda berhasil login kedalam platform terdapat menu utama API GATEWAY PLATFORM (CONSOLE) sebagai berikut:

Home
Halaman utama (dashboard) yang menampilkan ringkasan atau informasi umum dari sistem.
Connection
Digunakan untuk mengelola koneksi (seperti HTTP, Database, File, Javascript, dan Mail) ke berbagai layanan, host, atau aplikasi eksternal.
Filter
Data belum dilengkapi pada bagian filter.
Endpoint
Menu untuk mengatur titik akses (endpoint) komunikasi API atau URL yang digunakan untuk menghubungkan layanan.
Version
Menu untuk memantau atau mengelola versi dari aplikasi, layanan, atau modul yang sedang berjalan.
Service
Menu untuk mengelola layanan-layanan (services) utama yang aktif atau terintegrasi di dalam platform.
Consumer
Menu untuk mengelola data konsumen, klien, atau pihak luar yang mengonsumsi layanan dari sistem Anda.
Server
Menu untuk mengonfigurasi dan memantau server fisik atau virtual yang terhubung dengan infrastruktur.
Administration
Menu pengaturan sistem tingkat lanjut untuk mengelola hak akses, pengguna (user), peran (roles), dan konfigurasi administratif lainnya.

3.Proses Pembuatan API/Endpoint Baru

Pada Tools Console, team helpdesk dapat membuat API/Endpoint baru. Langkah-langkah yang harus dilakukan adalah sebagai berikut:

  1. Create Connection pada menu Connection.
  2. Create Endpoint pada menu Endpoint.
  3. Create dan Deploy Endpoint pada menu Service.
  4. Melakukan testing UAT sebelum dirilis ke publik.
