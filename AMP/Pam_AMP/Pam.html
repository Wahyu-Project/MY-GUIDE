CyberArk PAM (Privileged Access Management)

CyberArk PAM (Privileged Access Management) adalah solusi keamanan siber terkemuka yang dirancang untuk mengamankan, mengontrol, dan memantau akses istimewa (privileged access) dalam infrastruktur TI organisasi. Akses istimewa ini mencakup akun administrator, root, kredensial aplikasi, dan akses database yang memiliki hak penuh atas sistem.


Flow Proses CyberArk PAM

1. CyberArk Aplication

Penggunaan utama CyberArk PAM dilakukan melalui antarmuka web terpusat yang disebut PVWA (Password Vault Web Access) melalui halaman Website IDIRA. Pengguna berinteraksi dengan PVWA untuk mengambil kredensial, memulai sesi remote, atau mengelola akun istimewa. 2. Flow Pengecekan Basic CyberArk

CyberArk PAM (Privileged Access Management) dapat digunakan untuk melakukan pengecekan status server, resorce server, mengamankan, mengontrol, dan memantau akses istimewa (privileged access).

Menu Fungsi Menu
sudo su berfungsi untuk beralih atau mengambil alih hak akses penuh sebagai Administrator Tertinggi (Root) di dalam server Linux.
Uptime Digunakan untuk melakukan pengecekan Status & Start Uptime
Top Digunakan untuk memantau proses dan penggunaan CPU secara real-time.
free -h Digunakan untuk mengecek status penggunaan kapasitas RAM dan swap (total, terpakai, dan sisa) dalam format angka yang mudah dibaca (MB/GB).
systemctl status Merupakan standar utama pada sistem operasi Linux modern (seperti Ubuntu Server) untuk memantau status layanan (service) real-time sedang menyala (running), mati (stopped), atau mengalami crash (failed).

Format : systemctl status [nama_service]

Contoh : systemctl status elasticsearch
systemctl start berfungsi untuk menyalakan atau menjalankan kembali sebuah layanan (service) yang sedang dalam kondisi mati (inactive/stopped/dead) di server Linux.

Format : systemctl start [nama_service]

Contoh : systemctl start elasticsearch
