Monitoring Master & DB (Telegram)

Monitoring Master & DB (Telegram) adalah bagian dari layanan singkronisasi (DSP), yang befungsi untuk melihat status service pada layanan singkronisasi (DSP).

  • Informasi Akun
  • Landing Page Menu

1.Informasi User Akun

Master & DB (Telegram) dapat di akses menggunakan akun number 08811237095 dan untuk dapat login team helpdesk bisa berkoordinasi dengan Pak Ahmad Sandi selaku user dari number akun tersebut

2.Flow Monitoring Service

Ketika anda berhasil login Telegram menggunakan akun number 08811237095, team helpdesk bisa masuk ke grub SIG MONITORING lalu masuk ke menu notifikasi MASTER & DB dan akan terlihat detail status service seperti contoh gambar dibawah ini.

Master UP ✅
adalah informasi status service aktif.
Master Down 🚩
adalah informasi status service Down atau tidak aktif akibat server down atau after restart server sehingga perlu start up pada service aplikasi melalui PAM untuk proses start up agar service kembali aktif bisa ikuti dan klik panduan berikut : Start Service DSP
